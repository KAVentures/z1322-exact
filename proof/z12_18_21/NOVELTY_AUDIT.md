# Novelty and priority audit

**Audit date:** 3 August 2026

## Claim audited

The candidate new exact values are:

- Z(12,18;3,3)=108
- Z(12,19;3,3)=114
- Z(12,20;3,3)=120
- Z(12,21;3,3)=126

The value Z(12,22;3,3)=132 is not claimed as new. The 3-(12,6,2) Hadamard design furnishing the lower-bound family is classical and is not claimed as a new construction.

## Sources checked

1. Jay Bhan, Nicole Nobili, Srinivasan Raghuraman and Patrick Langer, *New Bounds for Zarankiewicz Numbers via Reinforced LLM Evolutionary Search*, arXiv:2605.01120v2 (May 2026). The abstract reports exact values only for Z(11,21), Z(11,22), and Z(12,22); its frontier table displays the four cells Z(12,n), 18 <= n <= 21, as open.
2. Sara Davies, Peter Gill and Daniel Horsley, *Improved upper bounds on Zarankiewicz numbers*, Discrete Mathematics 349(5) (2026), Article 114924, DOI 10.1016/j.disc.2025.114924.
3. arXiv and general web searches for the exact strings and notation variants:
   - `"Z(12,18;3,3)=108"`
   - `"Z(12,19;3,3)=114"`
   - `"Z(12,20;3,3)=120"`
   - `"Z(12,21;3,3)=126"`
   - variants using commas, spaces, and `Z_{3,3}(12,n)` notation
   - `"Z(12,n;3,3)=6n"`
4. GitHub code searches for the same exact values and notation variants.
5. The public `dfield/finite-zarankiewicz-closures` frontier repository and its current exact/bound tables.

## Result

No prior paper, preprint, or public repository stating any of the four exact values above was located in this audit. The May 2026 frontier paper is positive evidence that these cells were still open shortly before this work.

## Limitation

A literature search cannot prove the universal negative that a result has never appeared anywhere. An obscure, non-indexed, unpublished, or differently notated source could exist. The defensible wording is therefore:

> As of 3 August 2026, we located no prior publication or public preprint reporting these exact values.

Independent specialist review of priority and correctness is still required before making an unqualified first-discovery claim.
